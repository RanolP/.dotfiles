# LinearMouse

Mouse and trackpad customization.

**Managed by:** `nix/home/darwin/configs/linearmouse/linearmouse.json`, linked by `nix/home/darwin/default.nix`; the app comes from the Homebrew cask

## All Mice: Gestures

Middle-click drag gestures (threshold: 50px):

| Direction | Action |
|-----------|--------|
| Up | Mission Control |
| Down | App Exposé |
| Left | Move to right Space |
| Right | Move to left Space |

## All Mice: Other

| Setting | Value |
|---------|-------|
| universalBackForward | true |
| vertical scroll reverse | true (natural scrolling disabled) |
