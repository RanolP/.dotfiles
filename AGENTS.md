# Rules for Agents

- **GOLDEN RULE -- never compile, always download a prebuilt binary**: No package may be built from source. If a package would compile (Rust/C/etc.) because nixpkgs has no cached aarch64-darwin binary, do NOT accept the source build -- source it as a prebuilt instead: a Homebrew cask/formula (`nix/darwin/default.nix`), a mise binary backend (`aqua:`/`npm:`/`pipx:` in `nix/home/default.nix`), or a nix derivation that *fetches* the upstream release binary. Verify with `nix build .#darwinConfigurations.ranolp-work-MBP-26.system --dry-run`: if any real package (not a home-manager wrapper/activation/stub derivation) appears under "will be built", it is compiling -- stop and re-source it. Example: espanso is source-only in nixpkgs on darwin (and its Homebrew cask's nested-dmg unpack is broken under nix-homebrew), so `nix/home/darwin/default.nix` fetches the official release and mounts+`ditto`s the notarized app into `~/Applications` at activation -- download only, and unlike a `7zz` unpack it preserves the code signature (a re-packed bundle triggers "Espanso is damaged"; `codesign` can't re-seal in the nix sandbox).
- **The user runs the rebuild, not you**: After modifying any file under `nix/home/configs/`, finish the edits, then hand the user the apply command for THIS host to run in their own shell -- macOS: `! sudo darwin-rebuild switch --flake ~/.dotfiles/nix#ranolp-work-MBP-26`; Linux/WSL: `! home-manager switch --flake ~/.dotfiles/nix#ranolp-archwsl -b before-hm`. Say plainly that the change is pending until they run it. Hand the command over ONCE per generation, in the message where the batch of edits finishes -- a session that is still editing has not finished the batch, and a later turn repeating the same command adds nothing the user does not already have. The line goes at the END of the message that answers what the user actually asked, never in place of that answer. The `rebuild-enforcer` Stop hook shows the user the same reminder, also once per generation.
- **Direct main git workflow allowed here**: When requested, agents should create commits on `main` and push `main` to `origin` in this repository. Inspect status/diff first, stage explicit paths, and keep PR workflows out of scope.
- **REUSE 3.3 compliance -- every new file carries an annotation**: This repo is REUSE 3.3 managed. After adding a file, append its path to the matching `[[annotations]]` block in `REUSE.toml` (`precedence = "aggregate"`, `SPDX-FileCopyrightText = "2026 RanolP"`, `SPDX-License-Identifier = "MIT"`), extending an existing block whenever one already covers that area rather than opening a new one. Vendored third-party files keep their upstream copyright and license instead, with a comment naming the exact upstream version (see the `adf-schema-56.7.3.json` block). Verify with `reuse lint 2>&1 | grep <your-new-path>`, which must print nothing. Whole-project `reuse lint` exits non-zero today -- 123 legacy files (docs, `nix/flake.nix`, older hooks) predate the convention and stay untouched, so a red overall run says nothing about your change.
- **Never edit global config directly**: Never edit `~/.claude/settings.json` or any file under `~/.claude/` directly. All Claude config lives in `nix/home/configs/claude/` in this repo -- edit there instead.
