name: zoom-out
description: Zoom out and map an unfamiliar area of code at a higher level of abstraction.
disable-model-invocation: true
---

Go up a layer of abstraction. Give the user a map of all the relevant modules and callers for this area of code, showing how it fits into the bigger picture.

This is the static map. To trace how one action runs through that area (entry point, data flow, state owners) before changing it, use skill `how`.
